# OmO Web 0.1.5

**Send workspace files as resumable downloads.** Ask the assistant to send a file; the Web-only `send_file` tool posts an attachment in the conversation. There is no fixed per-file limit and no default storage quota. Set `OMO_WEB_ATTACHMENT_QUOTA_BYTES` to a positive byte count to cap total attachment storage. The service rejects new files that would exceed the quota without removing existing downloads. File contents travel only in the download, not in the chat stream.

**把工作区文件发成可续传的附件。** 在 Web 会话中让助手发送文件；助手可以用 Web 专属的 `send_file` 工具将下载入口发到对话里。不设固定单文件上限，默认也不设总配额。需要限制总占用时，设置 `OMO_WEB_ATTACHMENT_QUOTA_BYTES`（字节数）；超出配额时拒绝新附件，已有附件仍可下载。文件内容只在下载时传输，不走聊天流。

**Read rich Markdown in live replies and loaded history.** Assistant replies render CommonMark and GFM-style tables, task lists, links and footnotes, plus inline and display TeX math. Code blocks highlight known languages and can be copied. Raw HTML does not run; remote images only open on click.

**实时回复和按需加载的历史正文都支持 Markdown。** 助手回复可渲染 CommonMark 和常用 GFM 语法，包括表格、任务列表、超链接和脚注，也支持行内和块级 TeX 公式。已知语言的代码块可高亮、可复制。原始 HTML 不执行，远程图片不自动加载。

## Install or upgrade / 安装或升级

If [`0.1.5` is available on npm](https://www.npmjs.com/package/omo-web/v/0.1.5), install it directly. / 如果 [npm 已提供 `0.1.5`](https://www.npmjs.com/package/omo-web/v/0.1.5)，可直接安装：

```sh
npm install -g omo-web@0.1.5
omo-web --version
```

With repository access, you can also download `omo-web-0.1.5.tgz` and its `.sha256` from **Assets**, then verify and install locally. / 有仓库访问权限时，也可从 **Assets** 下载这两个文件，在下载目录校验并安装：

```sh
sha256sum -c omo-web-0.1.5.tgz.sha256 &&
  npm install -g ./omo-web-0.1.5.tgz &&
  omo-web --version
```

The npm launcher needs Node.js 18+; the Web service needs Bun and OmO Native. The separate `.tar.gz` runs with Bun without the npm launcher. Keep `OMO_WEB_DATA` and your OmO profile when upgrading. / npm 启动器需要 Node.js 18+；Web 服务需要 Bun 和 OmO Native。独立 `.tar.gz` 不需要 npm 启动器。升级时保留 `OMO_WEB_DATA` 和 OmO profile。

## Verification / 验证范围

The Linux acceptance checks include a real Native tool call, a Chromium download larger than 32 MiB, a forced connection interruption followed by byte-range recovery, and an exact SHA-256 match. These tests use an isolated local proxy, not a particular FRP deployment. Platform CI validates the launcher and HTTP behavior; it does not establish interactive Windows terminal or macOS compatibility. / Linux 验收使用真实 Native 发起工具调用，验证 Chromium 下载超过 32 MiB 的文件、中断后从断点恢复以及 SHA-256 一致。测试使用隔离的本地代理，不代表某个 FRP 部署已经验收。平台 CI 验证启动器和 HTTP 行为，不涵盖 Windows 交互终端或 macOS。
