# OmO Web 0.1.3

**Find long CLI sessions again.** Previous versions omitted a session from the sidebar and CLI History search if its log exceeded the 8 MiB preview limit. Large logs can now appear in both lists. A preview shows why the transcript is unavailable; **Continue in Web** still opens the same session when the native engine supports handoff and no other process holds it.

**修复长 CLI 会话搜不到的问题。** 之前，超过 8 MiB 的日志会同时从侧栏和「CLI 历史」搜索里消失。现在这类会话可以列出，打开时会说明无法预览；原生引擎支持换端且没有其他进程持有会话时，仍可选择「在 Web 继续」。

Title lookup samples the beginning and end of large logs. If neither contains a title, search by working directory instead. / 大日志只从首尾读取标题；如果两处都没有标题，可以按工作目录搜索。

## Install or upgrade / 安装或升级

This release is available on GitHub and requires repository access. The public npm registry's `latest` is separate. / 此版本从 GitHub 下载，需要仓库访问权限；公开 npm 的 `latest` 独立更新。

Download `omo-web-0.1.3.tgz` and `omo-web-0.1.3.tgz.sha256` from **Assets**. From the download directory:

从 **Assets** 下载上面两个文件，在下载目录校验并安装：

```sh
sha256sum -c omo-web-0.1.3.tgz.sha256 &&
  npm install -g ./omo-web-0.1.3.tgz &&
  omo-web --version
```

The launcher needs Node.js 18+, Bun and OmO Native. The separate `.tar.gz` and its `.sha256` are for the Bun-only server. Stop the old service before starting the new build, and keep your `OMO_WEB_DATA` and OmO profile. / 启动器需要 Node.js 18+、Bun 和 OmO Native。`.tar.gz` 是不含 Node 启动器的 Bun 运行包。升级时先停止旧服务，保留 `OMO_WEB_DATA` 和 OmO profile。

## Verification / 验证范围

Linux Chromium verified that the sidebar and CLI History can find an existing 50 MiB journal at desktop and phone widths. Separate regression tests exercise resume and holder refusal without changing that journal. Windows CI covers packaged launcher startup and remote access; interactive Windows launcher menus and native CLI handoff were not tested on Windows. macOS was not tested.

Linux Chromium 在桌面和手机宽度下验证了实际 50 MiB 会话的搜索。恢复和持有冲突用独立测试数据验证，没有修改真实会话。Windows CI 覆盖安装后启动与远程访问，未验证 Windows 交互式启动器与原生 CLI 交接；未测试 macOS。
