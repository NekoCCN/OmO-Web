# OmO Web 0.1.4

**Open long conversations without fetching megabytes at once.** The server sends the newest page first. Choose **Load older messages** for earlier pages or expand a long text message to fetch it in chunks. Loading history does not resend drafts, and changing branches invalidates the old page and text links.

**长会话不再一次下载几 MB 的正文。** 服务端先返回最新一页；按需加载更早记录，或展开长文本分块读取。读取不发送草稿，切换分支后旧分页和长文本链接失效。

- Opening a conversation no longer fetches the entire session tree. The overview stays usable if the tree, queue, Todo or memory details cannot be read. / 打开会话不再读取整棵树；树、队列、待办或记忆读不到时，概览仍可用。
- An oversized Native reply no longer stops the whole engine. The browser can recover from transient event-stream failures without resending input. / 单个超限回包不再停止整个 Native 引擎；浏览器可从临时事件流故障恢复，不会重发输入。
- Each transcript page is at most 40 messages or 256 KiB of JSON; long-text chunks are at most 64 KiB. Oversized attachments may be omitted with a notice. / 每页正文最多 40 条且不超过 256 KiB，长文本每块不超过 64 KiB。超大附件可能省略，并会提示。

## Install or upgrade / 安装或升级

If [`0.1.4` is visible on npm](https://www.npmjs.com/package/omo-web/v/0.1.4), install that exact version:

如果 [npm 已显示 `0.1.4`](https://www.npmjs.com/package/omo-web/v/0.1.4)，可以安装这个确切版本：

```sh
npm install -g omo-web@0.1.4
omo-web --version
```

With repository access, you can also download `omo-web-0.1.4.tgz` and its `.sha256` from **Assets**, then verify and install locally. / 有仓库访问权限时，也可从 **Assets** 下载这两个文件，在下载目录校验并安装：

```sh
sha256sum -c omo-web-0.1.4.tgz.sha256 &&
  npm install -g ./omo-web-0.1.4.tgz &&
  omo-web --version
```

The npm launcher needs Node.js 18+, and the Web service needs Bun and OmO Native. The separate `.tar.gz` runs with Bun without the npm launcher. Keep `OMO_WEB_DATA` and your OmO profile when upgrading. / npm 启动器需要 Node.js 18+，Web 服务需要 Bun 和 OmO Native；独立 `.tar.gz` 可以不经 npm 启动器运行。升级时保留 `OMO_WEB_DATA` 和 OmO profile。

## Verification / 验证范围

Linux Chromium and real Native were used to test a large conversation, older pages, chunked text, branch changes, and connection recovery. Windows CI covers the packaged launcher and remote access, not its interactive menus or native CLI handoff. macOS was not tested. / Linux 上使用 Chromium 和真实 Native 验证了长会话、向前翻页、分块文本、切换分支及重连。Windows CI 验证打包启动器与远程访问，不包含交互菜单或原生 CLI 交接；未测试 macOS。
