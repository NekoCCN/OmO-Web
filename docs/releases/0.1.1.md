# OmO Web 0.1.1

The terminal launcher now has **Access settings**:

- Set or change the access password without echoing it. Turn password protection off or back on without deleting the saved password. The browser username is `omo`.
- Turn HTTPS on or off, or generate a self-signed SSL certificate for the IP or DNS name you'll open in the browser. Generation requires OpenSSL 1.1.1+ on `PATH`; verify and trust the certificate on the client.
- Listen on loopback, a specific local IPv4 interface, or all IPv4 interfaces (`0.0.0.0`). Non-loopback access still requires HTTPS; passwordless startup from the launcher asks for confirmation when configured there.
- Settings are saved for the next start. Stop a running service before editing. Direct `omo-web serve` still reads environment variables only.

终端启动器新增「访问设置」：可以改密码、独立开关认证和 HTTPS、生成自签 SSL 证书，以及选择仅本机、指定网卡或 `0.0.0.0`。选择网卡不会修改防火墙规则。非本机监听仍必须用 HTTPS。

## Install or upgrade / 安装或升级

Requires Node.js 18+, [Bun](https://bun.sh/docs/installation), and [OmO Native](https://github.com/code-yeongyu/oh-my-openagent) for running sessions.

```sh
npm install -g omo-web@0.1.1
omo-web --version
omo-web
```

Without npm registry access, download `omo-web-0.1.1.tgz` and its `.sha256` from **Assets**, verify, then run `npm install -g ./omo-web-0.1.1.tgz`. The `.tar.gz` and its `.sha256` are for the Bun-only server, without the Node launcher. Keep your `OMO_WEB_DATA` and OmO profile when upgrading.
