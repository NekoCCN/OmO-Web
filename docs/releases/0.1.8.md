# OmO Web 0.1.8

## What's new

- **Current and historical runs are separate.** `/todo` shows the latest verified checklist on the current branch, and `/dag` shows current runs from the host. Open **History** to load read-only records; they never replace or count toward the current view. The host checks up to 256 recent DAG runs before filtering, so older matches may not appear.
- **DAG nodes and subagents have execution details.** See descriptions, progress, attempts, dependencies and reported reasoning. Configured, requested and effective models are separate. Jump between a node and its child task when their association is verified.
- **Open sessions by directory.** Choose an authorized working directory before browsing sessions. The sidebar groups sessions already opened in Web by directory. **Continue in Web** opens the original CLI journal.
- Skill instructions are collapsed by default without hiding your accompanying message. Tool cards remain readable while their stylesheet is loading or unavailable.

## 更新内容

- **当前执行与历史分开。** `/todo` 显示当前分支最新的可核验待办，`/dag` 显示宿主报告的当前运行。「历史」按需读取、只读，不替代当前，也不计入当前统计。宿主最多检查最近 256 次运行再筛选，更早的匹配可能看不到。
- **DAG 节点和子代理可查看执行详情。** 可查看描述、进度、尝试次数、依赖和宿主报告的推理档。配置、请求及实际生效的模型分别显示；关联经过核验时，节点和子代理任务可双向跳转。
- **从目录打开会话。** 先选授权工作目录，再浏览对应会话；侧栏按目录分组，只显示已在 Web 打开的会话。「在 Web 继续」仍使用原 CLI 日志。
- 技能说明默认折叠，不隐藏用户附带的任务文字。工具卡在样式加载中或加载失败时仍能正常阅读。

## Install or upgrade / 安装或升级

Once [npm lists `0.1.8`](https://www.npmjs.com/package/omo-web/v/0.1.8), install it directly. / [npm 上线 `0.1.8`](https://www.npmjs.com/package/omo-web/v/0.1.8) 后，可直接安装：

```sh
npm install -g omo-web@0.1.8
omo-web --version
```

Or download `omo-web-0.1.8.tgz` and its `.sha256` from **Assets**, then verify and install locally. / 也可以从 **Assets** 下载这两个文件，校验后在本地安装：

```sh
sha256sum -c omo-web-0.1.8.tgz.sha256 &&
  npm install -g ./omo-web-0.1.8.tgz &&
  omo-web --version
```

Keep `OMO_WEB_DATA` and your OmO profile when upgrading. The npm launcher needs Node.js 18+; the Web service needs Bun and OmO Native. The separate `.tar.gz` runs with Bun without npm. / 升级时保留 `OMO_WEB_DATA` 和 OmO profile。npm 启动器需要 Node.js 18+；Web 服务需要 Bun 和 OmO Native。独立 `.tar.gz` 不需要 npm 启动器。
