**OmO Web 0.1.0 是 OmO Native 的首个浏览器工作台版本。** 在同一个窗口里，你可以继续不同项目的会话、从终端交接到浏览器，或打开只读视图看进度。

## 亮点

- **会话与审批。** 新建、恢复和归档会话；接收流式回复、发送后续消息、停止回合，在浏览器处理原生 Agent 问题和工具审批。
- **工具卡与双语。** Todo 直接显示本次变更，Agent 卡可查看派发提示词。参数和回执可展开；运行侧栏支持上下文、用量、会话树、只读子代理和 DAG。左栏底部可以切换简体中文与 English。
- **有边界的 CLI 互操作。** 同一 profile 下可预览历史，再显式继续同一份日志；持有者保护防止双写。已连接的 CLI 可接收普通消息和精确停止请求；「跟随 CLI」入口只读。
- **本机默认。** 默认回环监听；跨设备访问要求密码和 HTTPS。模型凭据留在本机，OmO 仍负责执行和权限判断。

## 安装

先安装 [Bun](https://bun.sh/docs/installation) 和已配置模型的 [OmO Native](https://github.com/code-yeongyu/oh-my-openagent)。从 [v0.1.0 发布页](https://github.com/NekoCCN/OmO-Web/releases/tag/v0.1.0) 下载，不需要 GitHub 登录。

下载 `omo-web-0.1.0.tar.gz` 和 `omo-web-0.1.0.tar.gz.sha256` 到同一目录，再校验并启动。示例工作目录要换成真实存在的项目。

```sh
archive=omo-web-0.1.0.tar.gz
sha256sum -c "$archive.sha256" &&
  tar -xzf "$archive" &&
  OMO_WEB_WORKSPACES="$HOME/path/to/your-project" \
    bun --no-env-file "$PWD/omo-web-0.1.0/dist/server.js"
```

打开终端打印的地址（默认 `http://127.0.0.1:4317`）。包内已有运行资源与第三方许可，无需安装 npm 依赖。也可以[从源码启动](https://github.com/NekoCCN/OmO-Web/blob/main/docs/install-release.md#用户源码安装)；升级时保留 `OMO_WEB_DATA` 与使用中的 OmO profile。

## 验证范围

- 在 Linux 使用 Bun **1.4.5**、OmO Native **5.1.83**（Senpi **2026.11.23**）验收；解压包从独立工作目录启动并完成原生 RPC 握手。
- Windows 的验证覆盖文件浏览和目录授权，不等于完整 CLI 互操作；macOS 未实机复验。
- 这是单操作者工作台，不是多用户服务，也不替代完整 TUI。外部访问或部署前请阅读[使用与安全指南](https://github.com/NekoCCN/OmO-Web/blob/main/docs/usage.md#密码与远程访问)。
