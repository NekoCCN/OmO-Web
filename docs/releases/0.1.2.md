# OmO Web 0.1.2

- **Reverse proxies and tunnels:** Set **Access settings → Proxy origin** or `OMO_WEB_PROXY_ORIGIN` to the exact external HTTPS origin. Keep OmO Web on loopback when the proxy runs locally and terminates TLS. The proxy must preserve the original `Host`; forwarded headers do not override the origin or write-token checks.
- **Short passwords:** Passwords can be 1–128 printable ASCII characters. Fewer than 20 characters triggers a warning without blocking startup or sign-in. Private file permissions and the existing remote-access safeguards still apply.
- **Explicit Web commands:** `/compact [instructions]` uses native compaction when the session is idle. `/settings` and `/setting` open current-session settings; global configuration still belongs to the native terminal. Commands such as `/login` and `/reload` show terminal-only guidance instead of being forwarded.

内网穿透或反代可设置对外 HTTPS 入口，后端仍可只监听本机；代理须保留原始 `Host`。密码不足 20 位只提醒，不阻止保存或登录。`/compact [指示]` 调用原生压缩；`/settings` 或 `/setting` 打开当前会话设置。全局配置仍在本机终端修改。

## Install or upgrade / 安装或升级

Install the public package from [npm](https://www.npmjs.com/package/omo-web). The launcher needs Node.js 18+ and [Bun](https://bun.sh/docs/installation); running sessions also needs [OmO Native](https://github.com/code-yeongyu/oh-my-openagent).

```sh
npm install -g omo-web@0.1.2
omo-web --version
omo-web
```

With repository access, you can instead download `omo-web-0.1.2.tgz` and its `.sha256` from **Assets**, verify the download, and run `npm install -g ./omo-web-0.1.2.tgz`. The `.tar.gz` and its `.sha256` are for the Bun-only server without the Node launcher. Keep your `OMO_WEB_DATA` and OmO profile when upgrading.

## Verification / 验证范围

Windows CI exercised installed `omo-web.cmd` startup, private ACLs, password rotation, proxy origin checks and direct HTTPS. Interactive TUI menus were exercised on Ubuntu, not Windows. macOS was not tested. Linux Chromium verified sign-in, live events and a write through an HTTPS reverse proxy; this does not verify deployment-specific DNS or routing.
