# OmO Web · 操作界面与验收简报

**Target:** `public/index.html` 及后续嵌入的会话、管理和原生兼容面。  
**Mode:** Operate。**视觉权威：** [DESIGN.md](../../DESIGN.md)、`public/styles.css` 和当前工作台；延展原有体系，不换品牌、不改框架。  
**输入：** 获批 `omo-web-cli-parity` 计划的主用户、日常工作任务、Linux 范围、本机信任边界与双轨决定；复用已有确认，不视本简报为新权限或放行审批。产品范围见 [PRODUCT.md](../../PRODUCT.md)。

## Direction contract

**THESIS — 以会话为单位工作。** 用户始终能回答「这是哪个宿主和会话？现在轮到谁？接下来能做什么？」不把聊天、原生输出和管理堆成多个常驻仪表板。

**OWN-WORLD — 沿用现有工作台。** 使用语义色 token、系统中文无衬线与等宽路径/命令、原有密度、边线与间距；在同一套 `.button`、`.notice`、`.stack`、`.row`、`<details>`、原生表单和 `<dialog>` 上扩展。高频动作不进二级菜单；危险、选中、禁用和焦点各有非颜色提示。

**STORY — 找会话 → 看状态 → 发起或作决定 → 看原生结果。** 标志交互是「查看待答项」：不抢编辑焦点，用户主动跳到问题或审批，确认作用域、处理并回到可继续的位置。断线或结果未明时先查证，不猜成败。

**FIRST VIEWPORT — bounded list-detail + composer。** 宽屏保留 17rem 会话栏、会话标题与低频动作、48rem 阅读列、底行输入；`≤760px` 使用可开合会话抽屉，主区单列。对话是主滚动区，会话栏列表和模态只滚各自内容；长代码/原生终端可以局部滚动，不带动整页。首屏主动作随状态为「新会话」「发送」「停止」或当前待答项；不要用固定页脚压住交互。

**FORM — 已确定的工作台扩展。** 这是已批准壳内的局部扩展，非全屏新概念；不抽 seed、不做 comp。反馈只用于表现状态，减动时即时变化；不做展示型入场动画。

**FINISH —** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Task 3 只交设计约定和 before。实现、视觉修正与 finish review 属于后续节点。

## 状态与呈现约定

- **壳与身份：** 标题、完整工作目录、私有/共享宿主来源、连接状态分开。一个会话 `aria-current`；选择后在主区定位。标题可截断，完整路径必须有可聚焦、可触达的途径，不能只靠 hover/`title`。附着标明宿主与原生会话，断开写清仅影响哪个控制者。
- **空、加载、故障：** 区分未开始、空历史、筛选无结果和权限不可见。加载定位在目标区，命名状态且保留壳；离线保留草稿和已可读历史、说明哪些写操作暂不可用。错误在操作旁说明原因和下一步；对未知回执显示「结果未确认；先刷新状态」，不得自动重放。
- **写操作：** 先展示目标、原生权限及动作范围；提交待确认时锁对应动作而非整个工作台。成功以权威回执/重读显示，拒绝可读，可撤销或重试仅在实际支持时出现。永久授权、外部副作用或赴本机操作不可由通用确认悄悄替代。
- **路径与证据：** 显示「在工作台操作」「在浏览器原生终端操作」「在本机 OmO 继续」三种不同入口；仅在行级证据支持时标已验证。禁用例：「原生兼容未启用。工作台仍可使用。」私密提示：「此操作仅在本机 OmO 处理。请在本机重新发起。」附着退出：「断开此标签的附着；原会话继续运行。」独立退出按实际结束策略说明；不承诺自动续接。
- **共通视觉 oracle：** 下表每行都在 1440 和 390 CSS px、浅/暗主题取新图并核对 DOM；明暗都能读到标题、对象、禁用原因、错误和焦点。仅颜色变化或存在按钮不算通过。额外跑 320、760/761、触控、减动、长中文与无断点字符串。在 390 上操作可见且触区用现有 `--touch`；长列表/内容入指定滚动区；不靠缩字号找空间。键盘 Tab/Shift+Tab、Escape、返回焦点有可观察目标，数据刷新不抢焦点；读屏以可达名称和适度的 `status`/`alert` 通知为准，不逐 token 播报。
